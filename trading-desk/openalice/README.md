# OpenAlice Integration

OpenAlice should be the **cockpit**, not the risk engine.

We do **not** vendor OpenAlice into this repo because it is AGPL-3.0 and is a large active app. Instead, this desk integrates beside it:

```text
OpenAlice UI / workspace / inbox / MCP
        ↓ runs commands / headless prompt
Flip trading-desk
        ↓
zero-LLM scanner → preflight budget guard → low-burn TradingAgents wrapper → JSON decision
```

## Why this boundary

Good OpenAlice pieces:
- workspace UI and persistent terminal sessions
- headless workspace runs
- Inbox push surface
- market/news/research tool surface
- UTA/broker guard architecture for later paper/live execution

Keep in Flip desk:
- token-budget ledger
- zero-LLM scanner
- TradingAgents wrapper
- deterministic risk/budget gates
- generated decision JSON

Do not let OpenAlice execute trades yet. Research/paper only until the desk proves useful over forward tests.

## Install OpenAlice beside the desk

```bash
cd /root/flip/projects/trading-desk/Ai-digital/trading-desk
bash scripts/setup_openalice.sh
```

This clones/updates OpenAlice at:

```text
/root/flip/projects/trading-desk/OpenAlice-upstream
```

State is isolated under:

```text
trading-desk/.openalice/
```

Start OpenAlice:

```bash
cd /root/flip/projects/trading-desk/OpenAlice-upstream
OPENALICE_HOME=/root/flip/projects/trading-desk/Ai-digital/trading-desk/.openalice pnpm dev
```

Open the Vite UI URL OpenAlice prints, usually `http://127.0.0.1:5173`.

## Generate an OpenAlice workspace prompt

```bash
cd /root/flip/projects/trading-desk/Ai-digital/trading-desk
python scripts/openalice_bridge.py \
  --symbols SPY,QQQ,NVDA,TSLA,SMH,AAPL,MSFT \
  --max-finalists 3
```

It writes:

```text
trading-desk/runs/openalice_prompt.md
```

Paste that into an OpenAlice workspace, or use it for headless dispatch.

## Optional headless dispatch

If OpenAlice is running and you have a workspace id:

```bash
cd /root/flip/projects/trading-desk/Ai-digital/trading-desk
OPENALICE_WORKSPACE_ID=<workspace-id> \
OPENALICE_BASE_URL=http://127.0.0.1:47331 \
python scripts/openalice_bridge.py --agent shell
```

If OpenAlice is behind admin-token auth, include:

```bash
OPENALICE_ADMIN_TOKEN=<token>
```

The bridge calls:

```text
POST /api/workspaces/:id/headless
```

## Safe operating rule

OpenAlice instructions generated by this repo always say:

- research/paper mode only
- no broker staging/execution
- scan first with zero LLM calls
- preflight before model calls
- only analyze finalists
- use Flip desk JSON outputs as source of truth
